# Best Sellers: Platter technical challenge

A responsive Best Sellers section built from the supplied Figma design with semantic HTML, TailwindCSS and vanilla JavaScript.

**Live preview:** https://jlbellorin.github.io/platter-best-sellers/

## How to view

Open `index.html` in a browser. No build step, no install, no local server. Tailwind and the fonts load from a CDN, so the page renders the same from the filesystem as from the preview link.

Ten product cards. Desktop is an edge-to-edge slider you can drag, with a scrollbar thumb that grows from 4px to 6px on hover. Mobile shows the first four in a two-column grid, and **Show More** reveals the rest. Hovering an image cross-fades to a second one.
